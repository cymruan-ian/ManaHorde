KEEP YOUR COLLECTION CLOSE

Backups & sync

Google Drive

Merge changes from your devices and save a dated backup in your own Drive. Conflicting edits are kept for you to review.

Google Drive is not connected.

    Requires one-time Google setup in Settings. Sync runs when you press Sync now, while the app is open.

    Portable backups

    Download a JSON backup to keep or save to Google Drive yourself. Import it on another device to merge your collection, including its edit history.

    Conflicting edits

    If two devices change the same entry independently, choose the version to keep below. Download a backup first if you want to retain all versions outside the app.
    MAKE YOURSELF AT HOME

    Settings & install

    Google Drive setup

    Enter a Google OAuth Web application client ID. Use the same client ID on every device so they can access the same app-created backups. No client secret is needed.

    See README.md in the app folder for the setup steps. Your access token is held in memory only.

    Google AI (Gemini)

    Optional: enter a Gemini API key to generate live Google AI deckbuilding guides in the app.

    Install on Windows & Android

    Windows: open this app in Edge or Chrome, then choose “Install app” from the browser menu or address bar.

    Android: open the app’s HTTPS address in Chrome and choose “Add to Home screen” → “Install”.

    The localhost address only works on this computer. Android needs an HTTPS-hosted copy of these app files. Once installed and opened online, the app works offline. Card lookup and Drive sync need an internet connection.

    Local storage

    Your collection is stored in this browser’s IndexedDB. Keep regular backups: clearing browser/site data or removing a browser profile can erase it.
